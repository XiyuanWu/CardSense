# CardSense documentation

| Document | Audience | Purpose |
|----------|----------|---------|
| [installation.md](./installation.md) | **Developers** | Clone the repo, install dependencies, run backend / web / mobile locally |
| [usage.md](./usage.md) | **Users** | Sign up, navigate the app, and use core features (Web & Mobile) |
| [documentation.md](./documentation.md) | **Developers** | Architecture, data models, REST API, integration notes |

**Rule of thumb**

- **Installation** = “How do I get it running on my machine?”
- **Usage** = “How do I use CardSense after it’s running?”
- **Documentation** = “How is it built, and how do I integrate or extend it?”

Start with [installation.md](./installation.md) if you are setting up the project. Use [usage.md](./usage.md) for user flows. Use [documentation.md](./documentation.md) for API and system design.
