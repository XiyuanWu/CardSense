# CardSense documentation

| Document | Audience | Purpose |
|----------|----------|---------|
| [installation.md](./installation.md) | **Developers** | Clone the repo, install dependencies, run backend / web / mobile locally |
| [usage.md](./usage.md) | **Users** | Sign up, navigate the app, and use core features (Web & Mobile) |
| `development.md` *(planned)* | **Developers** | API overview, project conventions, testing, contributing |
| `architecture.md` *(planned)* | **Developers** | System design, apps, data flow |

**Rule of thumb**

- **Installation** = “How do I get it running on my machine?”
- **Usage** = “How do I use CardSense after it’s running?”
- **Development / architecture** = “How is it built and how do I extend it?”

Start with [installation.md](./installation.md) if you are setting up the project. Use [usage.md](./usage.md) if you are testing features or writing user-facing help.
